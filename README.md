## Собственный проект "Каталог игр"

Тема проекта: Каталог игр

Главный класс: games

Почему этот объект нужен программе:
Чтобы она понимала что и конкретно к чему относится,и также не нужно писать очень много данных или любую другую информацию

Какие данные хранит объект:

- жанр
- год выхода
- само название
- рейтинг

Какие значения задаются через конструктор:
- название
- рейтинг
- год выпуска

Какие значения можно задавать автоматически:
- жанр (ввод не требуется, изначально у меня жанр Action)
